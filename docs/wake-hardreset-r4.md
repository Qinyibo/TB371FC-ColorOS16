# wake-r4 待机唤醒修复候选（2026-11-01）

基于 wake-cache-r1：当屏幕唤醒前的触摸固件加载失败时，执行一次触摸芯片硬复位，再完整加载固件并继续原有校验。正常恢复流程不增加硬复位。

实机捕获过触控固件连续加载失败、显示链路启动失败的黑屏现场。测试中人为制造固件校验失败三次后，硬复位重试成功，触控恢复；还完成了多次短时唤醒。用户于 2026-11-01 反馈当前版本未再出现问题。故障根因、断开 USB 的深睡覆盖及双击唤醒尚未完整验证。
