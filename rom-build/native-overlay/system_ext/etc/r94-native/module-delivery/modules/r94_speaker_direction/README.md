# 四扬通话归还恢复修正版 v0.25

配套已核验的#35/#36/#37/#38内核和API19，不修改内核、HAL、固件、方向表或JNI。安装及本机检查见独立回执；仍未经过实际通话验证。

修复原保护逻辑在12次失败后永久停止归还请求的问题：前12次最多每500ms尝试，随后每5秒一次，直至驱动确认归还成功。失败状态仍归驱动持有，不能以回到MODE_NORMAL冒充成功。模式读取异常只开启同一恢复任务，不每100ms重复写入；重复模式/路由事件不会累积恢复任务。恢复期间禁止新的媒体旋转。

模式/路由查询异常统一进入相同的失败保护，不能由tick异常分支绕过。受控停用时先标记退出，迟到的显示/播放/设备/模式回调不能重新申请媒体旋转；停止重试只做归还。

这是恢复路径修复，不是通信共享拨号修复，也不是HAL媒体专属重构。100ms模式观察不能保证在通话路由生效前同步归还；永久硬件故障仍可能保持失败状态，日志不会谎报成功。

可经Magisk安装并重启一次，勿只覆盖运行中的jar。异常时停用模块并重启，恢复原0.23。需要实听呼入/呼出双向声音、音乐中来电、挂断恢复媒体及四方向；使用现有联合采样器记录CALL_MODE_RELEASE和音频路由。未得到用户功能反馈前不整包重刷。


新增首次启动修正：原ROM初始化脚本属于init oneshot服务，直接后台启动的四扬子进程可能随初始化收尾被清理。现在仅通过本机已有Magisk守护进程派生独立的常驻监督进程，不修改Root授权或服务策略；内部supervisor.lock仍保证只有一个控制器。不会不停重启崩溃helper。

本版Java/JNI/方向表与v0.24逐字节相同。既有关闭/移除标志仍优先；正常启停继续使用action.sh/stop.sh。此模块更新不更改boot、system_ext或已发布v13 ZIP。


0.26：仅把已核验的#39充电修复内核加入服务及JNI版本白名单，保留0.25的Java、方向表、通话保护和启动方式。没有修复尚待实测的真实通话声音。
