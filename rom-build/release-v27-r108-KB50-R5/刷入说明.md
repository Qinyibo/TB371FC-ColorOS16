# TB371FC ColorOS 16 v27 / r108 KB50 R5 候选整包

适用机型为 Lenovo TB371FC（Bootloader 产品名 `spinel`），须为已解锁的 A 槽。系统基线为 `OPD2413_16.0.0.210(CN01)`，启动镜像使用 #50 内核和官方 Magisk 31.1（31100）。

## 清刷流程

1. 备份应用、账号及个人文件。清刷会擦除 `userdata` 和 `metadata`。使用稳定的 USB 数据连接，确认平板电量至少 50%。
2. 按包外 `.sha256` 核对 ZIP，解压到独立目录，运行 `核验ROM.cmd`。
3. 在 Bootloader Fastboot 下运行 `1-连接检查.cmd` 和 `2-刷前检查.cmd`。运行 `清空数据刷入-32M断点续传.cmd`，按提示输入 `FLASH`。共 385 块。USB 中断时，在同一解压目录重新运行并保留进度文件。如果期间另行刷过 super，请从第一块重新开始。
4. 完成 Android 初始设置。开机引导完成后，Android 开始把 Magisk 管理器安装为普通应用，桌面动画组件同时初始化。若 ColorOS 显示「继续安装」或「安全验证」，请在平板上完成。打开 Magisk 后，如提示修复运行环境，请确认并等待重启。若管理器未安装，可运行包里的 `安装Magisk.cmd` 或手动打开 `assets/root/Magisk-v31.1.apk`。
5. 相机已完整预装。首次打开时按需授权，验证前后摄像头预览、拍照和保存。首次进入桌面后打开多个应用，用最近任务手势验证堆叠卡片。支持堆叠的 Launcher 已预置在系统镜像中。
6. Tinno 键盘配置已内置到 vendor 镜像。清刷进入桌面后，验证磁吸键盘打字、触控板、重新吸附和休眠唤醒后的输入。R5 候选尚待上述实机验收。

## 回退

完整回退请使用此前已验证的完整 ROM 和自己的数据备份。`assets/rollback/boot_a-r108-force-rek-rollback.img` 用于回退启动分区，SHA-256 为 `71340e8d8751c9951844c4bdbefb1bdb49f75ee8f41f06f4b33811b9a9f5aa3e`。
