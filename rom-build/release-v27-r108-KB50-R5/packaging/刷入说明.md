# TB371FC ColorOS 16 v27 / r108 KB50 R2 候选整包

适用机型为 Lenovo TB371FC（Bootloader 产品名 `spinel`），须为已解锁的 A 槽。系统基线为 `OPD2413_16.0.0.210(CN01)`。启动镜像使用已实机启动的 #50 内核与官方 Magisk 31.1（31100）。系统镜像内置完整版 ZUI 相机，Magisk 管理器按官方支持方式安装为普通应用。

## 清刷流程

1. 备份应用、账户及个人文件。清刷会擦除 `userdata` 和 `metadata`。使用 Windows 10/11 x64 和稳定的 USB 数据连接，确认平板电量至少 50%。
2. 按包外 `.sha256` 文件核对 ZIP，解压到独立目录，运行 `核验ROM.cmd`。刷写脚本会逐块核对 super 分块。
3. 在 Bootloader Fastboot 中运行 `1-连接检查.cmd` 和 `2-刷前检查.cmd`。
4. 运行 `清空数据刷入-32M断点续传.cmd`，按提示输入 `FLASH`。共 385 块。USB 中断时，在同一解压目录重新运行并保留 `super-parts-progress.json`。如果期间刷过其他 super，从第一块重新开始。
5. 等待 Android 首次启动并完成初始设置。打开相机，检查前后摄像头预览、拍照和保存。
6. 保持 USB 调试已连接，运行 `安装Magisk.cmd` 安装管理器。也可在平板上通过文件管理器打开包内的 `assets/root/Magisk-v31.1.apk`。若 ColorOS 显示「继续安装」或「安全验证」，请在平板上完成相应确认。打开 Magisk，核对管理器和核心均为 31.1。如果提示修复运行环境，确认并等待重启。
7. 清刷会移除之前安装的 Tinno HAL 模块。完成 Magisk 初始化后，在「模块 → 从本地安装」中选择 `assets/root/tb371fc_tinno_vintf_pair.zip`，再重启并检查磁吸键盘和触控板。

## 验收与回退

#50 启动镜像已在保留数据的平板上运行，并通过 144 Hz 下的多轮待机唤醒测试。低频黑屏仍需长期观察。首次开机完成初始设置后，系统还要完成桌面动画组件的加载与编译，最近任务的堆叠布局会在桌面重新加载后可用。

需要恢复整机镜像时，使用此前已验证的完整 ROM 和自己的数据备份。`assets/rollback/boot_a-r108-force-rek-rollback.img` 仅供回退启动分区，原 SHA-256 为 `71340e8d8751c9951844c4bdbefb1bdb49f75ee8f41f06f4b33811b9a9f5aa3e`。
