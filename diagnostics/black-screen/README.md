# 自然黑屏时的只读采集（r107 标记已覆盖）

只在自然出现黑屏、ADB仍可读时手动运行，不触发唤醒、重启、刷写或切换电源；不清日志、不往平板写临时文件。当前源仍保留完整dmesg，再在电脑过滤，并采集触控/DRM/背光/regulator与GPIOINFO元数据。缺节点和失败命令不会被当作硬件成功证据。

```powershell
.\Collect-BlackScreen.ps1 -Serial '你的ADB序列号' -AdbPath 'C:/android-sdk/platform-tools/adb.exe'
```

可指定 `-OutputDirectory` 为不存在的电脑目录。已有无线连接也可以传入其设备地址，不会自动配对或修改无线调试设置。

过滤覆盖9D、A0/REK、R97、R104与R107；仍须结合完整日志和同一次故障时间，不能仅凭计数判根因。GPIOINFO只查询已存在的线信息，不获取线句柄、不改方向，输出不等于实际电平。脚本不读取KTZ寄存器；厂家规定0x0F故障标志读后清除，不能把重复读取后的0当作没有发生故障。

此版本已通过PowerShell语法检查及已有自然故障日志的过滤回放；新增GPIOINFO命令在本机只读执行通过。完整脚本仍需在下一次自然故障验证，不为测试它制造黑屏或反复唤醒。原始采集留本机，分享前去除设备身份和应用等个人信息。诊断解释见[当前Grok交接](../../docs/black-screen-handoff-20261103.md)。
